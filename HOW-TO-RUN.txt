ITALIC 1.0 - Windows desktop companion
======================================

WHAT IT IS
A small 3D character who lives on your desktop. He walks, climbs your
windows, parachutes, sits at his desk, plants a flag, and now and then
fights a rubber statue of Anthropic.

HOW TO RUN
1. Unzip this folder anywhere you like.
2. Double-click Italic-1.0.exe.
3. That's it. There is no installer and no chat window.

The app lives in the system tray (bottom-right corner, near the clock).
Right-click the tray icon and choose "Quit" to close it.

FIRST LAUNCH
The first start takes a few seconds: the exe unpacks itself once into
%LOCALAPPDATA%\Italic. Later starts are immediate.

WINDOWS SMARTSCREEN
The exe is not code-signed, so Windows may show a warning the first time.
Click "More info", then "Run anyway".

CONTROLS
- Hover the mouse over him, then drag to move him. Release to drop him
  or throw him.
- He ignores the mouse during a battle or a door/flag scene.
- Everything else is automatic: roaming, climbing, parachuting, working,
  planting the flag, and fights.

ONE INSTANCE
Only one Italic can run at a time. Launching the exe again just brings
the running one back to the front.

REQUIREMENTS
Windows 10 or Windows 11, 64-bit. Nothing else.

HOW TO UNINSTALL
Italic installs nothing into Windows - no registry entries, no services,
no startup items, and no admin rights are needed.

1. Right-click the tray icon and choose "Quit".
2. Delete Italic-1.0.exe (or the whole unzipped folder).
3. Delete the folders it left behind. Press Win+R, paste a path, press
   Enter, and delete the folder:
     %LOCALAPPDATA%\Italic    (the unpacked app, about 300 MB)
     %APPDATA%\Italic         (cache and preferences)
     %APPDATA%\italic         (left by older builds)

That is the whole uninstall. To use it again, just download and run it.

If there is no tray icon but the process is still running: Task Manager
-> Details -> end Italic.exe, then delete the folders above.

VERSION
Italic 1.0
